Privacy policy

Last updated: 28 October 2026.

SeatSync hub is a personal desktop tool used only by its owner, on the owner's own computer.

What it accesses

With the owner's Google sign-in it uses one permission: read-only access to Google Sheets (spreadsheets.readonly). It reads the cells of sheets the owner can already open. It never creates, changes or deletes anything in Google.

Where data goes

The sign-in token and the data read stay on the owner's computer. Nothing is sold, shared with anyone, or sent to any server other than Google's own.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
